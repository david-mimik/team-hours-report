Install team-hours-report on mimOE

For IT and developers · Windows or macOS · about 30 minutes. team-hours-report is one mim on mimOE with two pages: Team Time (exact hours from Tempo, by person, week and SDLC phase) and the Report builder (ask in a chat; Claude builds dashboards with burndown, velocity, flow and more). It only reads Jira and Tempo.

1Install the tools

mimOE

  1. Download mimOE Studio from mimoestudio.mimik.com: accept the agreement, choose WindowsmacOS, download and run the installer.
  2. Open mimOE Studio and click Install Runtime. When it asks how mimOE runs, choose External (the report connects to mimOE on localhost:8083), then Connect.
  3. Studio's Overview means mimOE is running. The runtime writes the node's keys to .mimoe/mimoe-api-key.env in your home folder (C:\Users\<you>\.mimoe\) (~/.mimoe/); the deploy script reads them from there.

Node.js and Git Bash

  1. Install Node.js 22 LTS from nodejs.org (Windows Installer, .msi, default options).
  2. Install Git for Windows from git-scm.com (default options). It includes Git Bash.
  3. Open Git Bash from the Start menu. Use it for every command below.

Use Git Bash, not PowerShell or Command Prompt. npm run deploy does not work from them: run the commands exactly as written here, in Git Bash.

  1. Install Node.js 22 LTS from nodejs.org (macOS Installer, .pkg), or with Homebrew: brew install node@22.
  2. Open Terminal (Applications → Utilities). Use it for every command below.

Check:

node -v      # v22.12 or newer
curl -s -o /dev/null -w "mimOE answers: %{http_code}\n" http://localhost:8083/mcm/v1/mims
v22.x.x
mimOE answers: 403

A 403 (or 401) is right here: mimOE is answering and asks for its key. 000 means mimOE is not running: start it from mimOE Studio.

2Create two tokens

  • Atlassian API token: id.atlassian.com → Security → API tokens → Create API token.
  • Tempo token: in Jira, Apps → Tempo → Settings → API Integration → New token.

Tokens act as you. Never email them, paste them in a chat or commit them. They stay in .env on this computer and in the mim's settings on this node; the browser never sees them.

Then install the dependencies (about 2 minutes):

npm run install:all

4Build and deploy

This builds the page and the mim, deploys the mim on mimOE and uploads the page into it (about 2 minutes):

npm run build
bash mim/scripts/deploy.sh --redeploy
Docker image package created successfully!
upload deploy/team-hours-report-v1-0.1.0.tar
deploy team-hours-report
healthcheck: {"status":"ok","info":{…,"apiRoot":"/api/team-hours-report/v1",…
uploaded 368 page files
report UI:   http://localhost:8083/api/team-hours-report/v1/

First time: lines like remove mim … only appear when an older copy was there. Redeploying is safe: it replaces the mim and empties its copy of the worklogs, which the report reads again by itself (about 20 seconds).

5Connect Claude for the Report builder chat

The chat runs on Claude Code with your own Claude login, the same way Team Advisor does it: through Muster, Team Advisor's Claude Code engine, which mimOE's MCP gateway runs. Skip this step if you only need Team Time.

  1. Install Team Advisor and run its Setup once, so the Claude Code engine row shows ✓ (see the Team Advisor install guide). Sign in to Claude Code if it asks.
  2. Check that Muster answers: 
    curl -s http://127.0.0.1:5191/agent/v1/healthcheck
    {"status":"ok"}
  3. Copy Muster's key into .env (the command does not show it): 
    node -e "const fs=require('fs'),os=require('os'),p=require('path');const k=((JSON.parse(fs.readFileSync(p.join(os.homedir(),'.mimoe','mcp-gateway.json'),'utf8')).mcpServers.muster||{}).env||{}).MUSTER_API_KEY;if(!k){console.log('Muster has no key: run Team Advisor Setup');process.exit(1)}const e=fs.readFileSync('.env','utf8');fs.writeFileSync('.env',/^MUSTER_API_KEY=.*$/m.test(e)?e.replace(/^MUSTER_API_KEY=.*$/m,'MUSTER_API_KEY='+k):e+'\nMUSTER_API_KEY='+k+'\n');console.log('MUSTER_API_KEY saved in .env')"
  4. Deploy again so the mim gets the key, then give Claude the report's tools: this registers the mim in the MCP gateway and adds it to Muster's gateway key. 
    bash mim/scripts/deploy.sh --redeploy
node mim/scripts/claude-setup.cjs
    claude: MCP server team-hours-report registered (/api/team-hours-report/v1/mcp)
claude: granted team-hours-report to Muster's gateway key

No Team Advisor? Set CHAT_ENGINE=local in .env and deploy again: the chat then uses the node's local model (Qwen3.5-4B-Q8_0, which must be in mimOE's model store). It is slower and handles fewer charts per answer.

6Open the report and check it

  1. Open http://localhost:8083/api/team-hours-report/v1/team-time.html. The first time it says there is no data yet: click Sync now (about 20 seconds).
  2. Team Time opens on Hours: the last 3 months by week, with total hours, people and average per person, each compared with the previous period.
  3. Click ← Report builder (or open http://localhost:8083/api/team-hours-report/v1/), then Sprint dashboard. Claude builds KPIs, burndown, burnup, tasks by status and tickets per person in about 25 seconds.

Done when: Team Time shows the green line “Rows, columns and the total add up exactly and match Tempo to the minute”, and the Sprint dashboard fills the canvas.

Bookmark both pages. Anyone on this computer can open them; to share with others, see Keep it private below.

Keep it private

  • The pages show per-person hours. They are served by mimOE on this computer (localhost).
  • To protect writes (page upload, sync, datasets), set WRITE_API_KEY in .env before deploying; scripts then send it as Authorization: Bearer <key>.

Update or remove

Update to a new version of the folder

npm run install:all
npm run build
bash mim/scripts/deploy.sh --redeploy
node mim/scripts/claude-setup.cjs      # if you did step 5

Your .env is kept. Open Team Time once and click Sync from Tempo (or just ask the chat: it syncs by itself).

Remove

node mim/scripts/claude-setup.cjs --remove   # if you did step 5: removes the gateway server and Muster's grant
bash mim/scripts/deploy.sh --remove

Then delete the folder. Revoke the Atlassian and Tempo tokens if nobody else uses them.
